\# E-Commerce Sales \& Customer Analytics



\## Project Overview



This project analyzes e-commerce sales and customer purchasing behavior using MySQL.



The objective is to identify sales trends, customer behavior, top-performing products, revenue contribution, profitability, and important business KPIs using SQL.



\## Tools \& Technologies



\- MySQL

\- SQL

\- MySQL Command Line

\- Git \& GitHub



\## Database Structure



The database `ecommerce\_analytics` contains:



\- `customers` - Customer information

\- `categories` - Product categories

\- `products` - Product details, pricing and inventory

\- `orders` - Customer orders and order status

\- `order\_items` - Products and quantities in each order

\## Key Business Insights



\- Total delivered revenue was \*\*₹49,418\*\*.

\- Electronics generated the highest category revenue at \*\*₹22,490\*\*.

\- Wireless Headphones generated the highest product revenue at \*\*₹9,996\*\*.

\- Smart Watch generated \*\*₹7,998\*\* in revenue.

\- Rahul Sharma was the highest-value customer with \*\*₹15,391\*\* in revenue.

\- Repeat customer rate was \*\*22.22%\*\*.

\- June generated \*\*₹25,183\*\*, while July generated \*\*₹24,235\*\*.

\- July revenue decreased by approximately \*\*3.76%\*\* compared with June.
